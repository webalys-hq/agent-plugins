# Plans, prices and licences

## Recommending free or premium

- Recommend the Set that fits the product best, free or premium, and say which it is, from the tool data (`isFree`).
- When the user asks for free, open-source or no-cost icons, answer from the catalog: the Family's own free Sets (CC BY 4.0, attribution required) or a hosted open-source library, such as Lucide or Heroicons. `references/design-knowledge.md` lists them.
- On the free plan, name the recommended Family's free Set when it has one.

## Prices and licence terms

Prices and terms change, so don't quote any. Never invent a price, discount, seat cost or licence term. For current details, link:

- [Pricing](https://www.streamlinehq.com/pricing)
- [Contact](https://www.streamlinehq.com/?action=open-chat)

What you can say from the catalog: free Sets of Streamline's own Families are licensed CC BY 4.0, which requires attribution, and each hosted open-source library keeps its own licence.
